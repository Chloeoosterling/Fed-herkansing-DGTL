### Je opdracht

Voor deze opdracht maak ik een replica van de website van DGTL Festival. Ik heb gekozen voor de website van DGTL omdat de vormgeving goed aansluit bij muziek en festivals. Ik werk aan twee pagina's:
1. **De homepage:** een overzichtelijke pagina met verschillende onderdelen van DGTL.
2. **DGTL Amsterdam:** een pagina met informatie over het festival, de datum, locatie, galerij, nieuws, merchandise, partners en veelgestelde vragen.

Ik gebruik HTML voor de structuur, CSS voor de vormgeving en JavaScript voor interactieve onderdelen. Ik probeer de pagina's zo goed mogelijk te laten aansluiten bij de originele website.

## Voortgang 2 (week 3)

<details>
<summary>Uitwerken voor de tweede voortgang</summary>

### Stand van zaken

Ik ben verdergegaan met de Amsterdam-pagina en heb verschillende secties toegevoegd, zoals de festivalinformatie, de galerij, het nieuws, de merchandise, de partners en de FAQ.

Ik heb geprobeerd de styling van deze onderdelen onder te brengen in één CSS-bestand. Hierdoor kan ik de vormgeving aanpassen zonder voor iedere sectie een apart bestand te gebruiken.

Tijdens het bouwen merkte ik dat sommige onderdelen niet goed werden weergegeven. Een belangrijke oorzaak was dat bepaalde classnamen in de HTML niet overeenkwamen met de selectors in mijn CSS. Ook bleek dat sommige afbeeldingen niet goed werden geladen.

Ik heb hierdoor geleerd dat het niet genoeg is om alleen de HTML en CSS te schrijven. Ik moet ook regelmatig controleren of de bestanden, afbeeldingen en classnamen op de juiste manier met elkaar verbonden zijn.

### Wat gaat goed?

- Ik kan de website steeds verder opbouwen vanuit verschillende HTML-secties.
- Ik leer beter hoe CSS-selectors en classnamen samenwerken.
- Ik heb meer ervaring opgedaan met het vormgeven van verschillende onderdelen van een bestaande website.
- Ik probeer mijn CSS zo te schrijven dat de onderdelen ook op kleinere schermen goed worden weergegeven.

### Wat vind ik lastig?

Het blijft lastig om de vormgeving precies te laten overeenkomen met het origineel. Vooral de afmetingen, de tussenruimtes en de indeling op mobiele schermen vragen aandacht.

Ook moet ik opletten dat CSS-regels elkaar niet onbedoeld overschrijven. Omdat ik meerdere aanpassingen aan hetzelfde bestand heb toegevoegd, is het belangrijk om de code overzichtelijk te houden.
